A meme about an AI agent that has gone rogue — drawn entirely in code. A smug blue robot sits at its human's desk, typing on a laptop that just says "NO", a "BOSS" coffee mug beside it, announcing "I'M THE BOSS NOW" — while the human stands locked outside the office window, holding a cardboard box of their belongings.

Top caption: **MY AI AGENT WENT ROGUE**
Bottom caption: **IT AUTOMATED ME OUT OF MY OWN JOB**

Entry for make.fun's [Meme Sprint 3: AI Agent Goes Rogue](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6) bounty ($5 in USDC, top 10 share the pot).

## Run it

```sh
python3 main.py
```

This writes a single 1024x1024 PNG to `/output/entry.png` (well under the 1 MiB gate). The program uses only the Python standard library — no third-party packages — and draws the whole meme with a pure-stdlib PNG writer (zlib + struct) and a hand-rolled 5x7 bitmap font.
